# Python Interface for Tecan Fluent Liquid Handlers

## Description

This repository provides a Python interface for controlling selected functions of Tecan Fluent liquid handlers through FluentControl.

The FluentControl API is briefly described in Chapter 15 ("API") of the *FluentControl Application Software Manual*:

https://www.tecan.com/knowledge-portal/fluentcontrol-software-manual

This library uses the `Execution Channel` feature via the `Tecan.VisionX.API.V2` .NET library, which allows an external API client to trigger script command execution in FluentControl. The current implementation supports selected pipetting operations and a subset of worktable configuration functions.

The author did not have access to the official Tecan FluentControl SDK during development of this library. This implementation was based on the limited information available in the *FluentControl Application Software Manual*, type reflection of the `Tecan.VisionX.API.V2` .NET library, and analysis of XML files generated by FluentControl when exporting scripts.

This library is provided as-is. As with any software that controls automated motion systems, users should exercise appropriate caution and verify all operations before running experiments on hardware.

The implemented features were actively used and tested by the author on a Tecan Fluent 1080 system. However, the author no longer has access to a Tecan Fluent instrument at the time of release. As a result, maintenance, validation, and troubleshooting on different FluentControl versions, hardware configurations, or operating system environments may require additional effort from users.

## Dependencies

The only required Python dependency is `pythonnet`, which provides the `clr` module used to access the `Tecan.VisionX.API.V2.dll` .NET library located in:

```text
C:/Program Files (x86)/Tecan/FluentControl
```

Install `pythonnet` with:

```shell
pip install pythonnet
```

## Usage

### 1. Create an API channel in FluentControl

In FluentControl, create a script named `APIChannel-Demo`, configure the worktable, and add the `Create API Channel` script command. To set up the worktable programmatically through the API, see Step 4.

### 2. Start the FluentControl script manually

Start the script in FluentControl and wait until it reaches the `Create API Channel` command.

### 3. Alternatively, start the script through the API

```python
import time
from tecan_fluent.tecan_ctrl import Tecan

dev = Tecan()

dev.rt.PrepareMethod('APIChannel-Demo')
while str(dev.rt.GetFluentStatus()) != 'RunModePreparingRun':
    time.sleep(0.2)

dev.rt.RunMethod()
dev.wait_channel()
```

### 4. Set up the worktable through the API

```python
# Add `FCA, 1000ul Filtered SBS` to `Nest7mm_Pos` position 5,
# and label it `P1000[001]`.
dev.add_labware(
    label='P1000[001]',
    type='FCA, 1000ul Filtered SBS',
    location='Nest7mm_Pos',
    position=5,
)

# Add custom labware `96 Deep Well 1.3ml Thermo 260251`
# to `Nest7mm_Pos` position 11, and label it `SrcPlate`.
dev.add_labware(
    label='SrcPlate',
    type='96 Deep Well 1.3ml Thermo 260251',
    location='Nest7mm_Pos',
    position=11,
)

# Add custom labware `96 Deep Well 1.3ml Thermo 260251`
# to `Nest7mm_Pos` position 17, and label it `DestPlate`.
dev.add_labware(
    label='DestPlate',
    type='96 Deep Well 1.3ml Thermo 260251',
    location='Nest7mm_Pos',
    position=17,
)
```

### 5. Pipette with LiHa or FCA

```python
# Mount tips on channels 0, 1, and 2 of the FCA.
dev.liha_get_tips(
    i_selected_tips=[0, 1, 2],
    diti_type='FCA, 1000ul Filtered SBS',
)

# Mix 300 µL for 3 cycles in wells A1, B1, and C1 of SrcPlate
# using tips 0, 1, and 2 and the custom liquid class `YeastCulture Mix`.
dev.liha_mix(
    n_cycles=3,
    volumes=[300, 300, 300],
    i_selected_tips=[0, 1, 2],
    labware='SrcPlate',
    i_selected_wells=[0, 1, 2],
    liquid_class='YeastCulture Mix',
)

# Aspirate 200 µL from wells A1, B1, and C1 of SrcPlate
# using tips 0, 1, and 2 and the custom liquid class `YeastCulture`.
dev.liha_aspirate(
    volumes=[200, 200, 200],
    i_selected_tips=[0, 1, 2],
    labware='SrcPlate',
    i_selected_wells=[0, 1, 2],
    liquid_class='YeastCulture',
)

# Use wellname96_to_tecan_well_no(...) to convert well names
# to Tecan well numbers:
#   wellname96_to_tecan_well_no('A1') -> 0
#   wellname96_to_tecan_well_no('B1') -> 1

# Dispense 200 µL into wells A1, B1, and C1 of DestPlate
# using tips 0, 1, and 2 and the custom liquid class `YeastCulture`.
dev.liha_dispense(
    volumes=[200, 200, 200],
    i_selected_tips=[0, 1, 2],
    labware='DestPlate',
    i_selected_wells=[0, 1, 2],
    liquid_class='YeastCulture',
)

# Drop tips to waste. The default diti_waste is
# `MCA Thru Deck Waste Chute_1`; an alternative `diti_waste`
# can be specified depending on the worktable configuration.
dev.liha_drop_tips(i_selected_tips=[0, 1, 2])
```

### 6. Pipette with MCA

```python
# Get the head adapter. The default head_adapter is `EVA[001]`.
dev.mca_get_head_adapter()

# The following functions can be used to control the MCA.
# This API library currently supports only whole-plate pipetting.
# Partial tip mounting with an offset, and aspirating/dispensing with
# an offset, should be possible but are not yet implemented in
# `command_elements_mca.py`.

dev.mca_get_tips(labware=...)
dev.mca_aspirate(volume=..., labware=..., liquid_class=...)
dev.mca_dispense(volume=..., labware=..., liquid_class=...)
dev.mca_drop_tips()
dev.mca_drop_tips_back_to_source()
```

### 7. Finish using the Execution Channel
```python

# Finish execution of the Execute Channel
dev.ch.FinishExecution()
```

### 8. Runtime controller

```python
# `dev.rt` is the RuntimeController.
# Use autocompletion, or refer to the FluentControl Application Software Manual,
# for the list of functions provided by RuntimeController.
# Use `help()` to inspect the expected argument types of the functions.

# Some functions provided by RuntimeController include:
dev.rt.PrepareMethod(...)
dev.rt.RunMethod()
dev.rt.PauseRun()
dev.rt.ResumeRun()
dev.rt.StopMethod()
dev.rt.CloseMethod()

dev.rt.GetFluentStatus()

dev.rt.GetVariableNames()
dev.rt.GetVariableValue(...)
dev.rt.SetVariableValue(..., ...)
dev.rt.ResolveExpression(...)

dev.rt.InteriorLight(True)
dev.rt.InteriorLight(False)
```
